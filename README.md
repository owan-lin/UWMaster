## 启动

1. 双击 `start.cmd`，或在文件夹中运行 `powershell -ExecutionPolicy Bypass -File .\start.ps1`。
2. 浏览器会打开 `http://127.0.0.1:8765`。也可用 `D:\DevTools\Python\pythoncore-3.14-64\python.exe server.py` 手动启动。启动器会验证页面响应；启动失败的日志在 `data/server-error.log`。

## 使用

- 左侧可按课程查看并展开大纲评分规则及核查来源；上方可筛选未来 7 天、全部学期、待确认、已完成并搜索。日历支持周视图、月视图和日期导航。
- 待办标题在新标签页直接打开快照记录的任务来源；“详情与备注”仍打开本地详情。没有有效来源链接时，标题打开本地详情。部分尚未发布独立作业页的任务仍链接课程介绍页，以后核查时可更新为具体作业入口。
- 待办与周／月日历共用课程配色：MATH 126 蓝色、CSE 123 红色、CSE 190 绿色、CSE 391 橙色；同课程按作业、课前材料、到课、测验等类型使用不同深浅，并保留文字分类。
- 待办分类与每周更新先遵循 `TASK_RULES.md`。CSE 123 lecture 非必到，不纳入必做待办；PreLect 纳入待办与日历，标为“计分 · PreLect”。课前完成时间按个人课程开始时间提醒，详情保留平台原始截止；两种时间不混用。Ed 明确已完成的材料保留在全部学期，不再列为未来待办。
- 勾选任务、填写个人备注会保存到 `data/user_state.json`；导入新快照或重启服务都保留。`scored` 仅表示来源已评分，绝不会自动标记为完成。
- 勾选成功后移入同页“已完成”分区；分区按课程和搜索筛选，不限截止日期。“查看全部已完成”清除课程和搜索限制；取消勾选可恢复任务。勾选或恢复后不显示成功提示栏、不自动滚动或跳转焦点，保存后保留页面和列表滚动位置。“全部学期”日历包含已完成任务，“未来 7 天”日历只显示未完成事项。
- 待办标题栏的“已完成”清除课程／搜索限制并展开分区；“＋”打开与详情同款的添加表单，可选择课程、分类、日期／时间、详情和来源。时间按西雅图填写；无日期的手动任务也显示在待办中。详情中的“删除任务”从面板隐藏任务，并提供撤销；来源再次导入不会恢复已删除任务。手动任务与删除记录保存在 `data/manual_tasks.json`，备注与完成记录仍单独保留。
- “导入核查快照”会校验 schema，保留个人状态，不会因为新快照中暂时没有某任务而删除本地完成/备注记录。导入会写入变更历史。
- “导出未完成 ICS”只导出已核实且具有明确 `due` 的未完成任务。只有日期的项目输出全天事件；有 offset 的日期时间会按其真实时刻导出，课程还保留结束时间、课程代码和原始来源链接。暂定或有矛盾的日期不导出。
- “下载 JSON 备份”下载当前显示的合并快照。应用数据原子写入，并保存单份 `.bak` 备份。

## Beta 检索与更新

- `/retrieval.html`：逐课编辑要求与 HTTPS 来源。共用规则来自当前 `TASK_RULES.md`，不会被旧快照替换；课程要求保存在忽略的 `data/retrieval_settings.json`。
- “检索这门课的来源”在后台读取公开 HTML／文本，最多并行四个来源。登录页面、PDF 和无法读取的来源标记为需单独核查；读到网页文字不等于已核实任务。当前结果保存在服务内存，重启后重新检索。
- 下载检索要求或来源文字可交给后续采集器；包含课程快照，不包含个人完成状态和备注。

- 原待办、课程颜色、标题来源链接、详情／备注、已完成分区、周／月历、搜索、JSON 备份、导入与 ICS 保持可用。后端更新需重新启动服务，前端刷新即可。
- 验证：`node tests_frontend.cjs`、`python tests.py`、`python tests_beta.py`；Beta HTTP 测试使用项目内隔离数据与随机端口。

## 文件边界

`snapshot.json` 是唯一的核查数据源；`data/` 是应用生成的本地状态。手动导入和自动核查都通过合并方式写入该文件：某一次来源漏掉的任务仍会保留，个人完成状态和备注独立保存在 `data/user_state.json`。自动更新可使用 `python import_snapshot.py --input 新快照.json`。

## 数据格式

使用用户已给出的 `schema_version: 1`：包含 `term`、`courses`、`tasks`、`changes`、`warnings`。导入至少核验：学期标识、课程/任务 ID 唯一性、任务课程关联、标题，以及 `due` 的 ISO 时间或 `YYYY-MM-DD` 格式。详尽字段由核查快照提供。
